# PortfolioReloaded

Single-page portfolio and interactive resume built with the T3 stack (Next.js, TypeScript, Tailwind CSS, tRPC), deployed on Vercel.

See [PROJECT_CHARTER.md](./PROJECT_CHARTER.md) for goals, scope and conventions.

## Commands

- `npm run dev` – start dev server at http://localhost:3000
- `npm run typecheck` – type check
- `npm run build` – production build

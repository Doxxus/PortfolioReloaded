# PortfolioReloaded

A single-page portfolio and interactive resume showcasing my projects, skills, work experience, and links.

Live at [folio.doxxus.ca](https://folio.doxxus.ca).

## Highlights

- Smooth, scroll-driven animations across sections (using Motion and Lenis).
- Projects pulled live from GitHub, enriched with curated descriptions.
- Now much more responsive and performant on desktop and mobile.

## Built With

[Next.js](https://nextjs.org), [TypeScript](https://www.typescriptlang.org), [Tailwind CSS](https://tailwindcss.com), [tRPC](https://trpc.io), [Motion](https://motion.dev), and [Lenis](https://lenis.darkroom.engineering), deployed on [Vercel](https://vercel.com).
